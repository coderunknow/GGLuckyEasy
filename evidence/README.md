# Evidence guide

- `final-local-audit.log`: complete audit output for the checked-in source revision.
- `ci-audit.log`: generated by GitHub Actions for the exact CI run; not a historical checked-in log.
- `unit-tests.log`: historical/targeted test output; use `final-local-audit.log` or CI output for current test counts.
- `event-results.json`: per-event mock results accepted only when registry, operations, and test-file hashes match the catalog generator.
- `build.json`: semantic nested-pack inspection and current artifact hashes.
- `probability.json` / `.csv`: seeded distribution output.
- `performance.json`: host-only Node benchmark, not mobile evidence.
- `coderabbit-*.json`, `review-status.json`: review triggers, findings, and statuses tied to their recorded PR heads.

Mock and host results are never real Bedrock/device evidence. Retail and multiplayer coverage remains separately documented as UNVERIFIED/BLOCKED.
